# 🛡️ Soldier Client

یک کلاینت VPN سریع، سبک و امن مبتنی بر **Xray-core**.

**Soldier Client** یک کلاینت VPN برای اندروید است که با الهام از پروژه فوق‌العاده **v2rayNG** توسعه یافته و با افزودن قابلیت‌های جدید، بهینه‌سازی‌ها و امکانات کاربردی، تجربه‌ای بهتر از اتصال و سازگاری با شبکه را ارائه می‌دهد.

> ⚠️ این پروژه با الهام از **v2rayNG** ساخته شده است و بدون تلاش ارزشمند توسعه‌دهندگان آن امکان‌پذیر نبود. از تیم توسعه‌دهنده v2rayNG و جامعه Xray-core بابت این پروژه متن‌باز فوق‌العاده صمیمانه سپاسگزاریم.
