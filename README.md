# 🛡️ Soldier Client

A fast, lightweight and secure VPN client powered by **Xray-core**.

Soldier Client is an Android VPN client inspired by the excellent **v2rayNG** project and built on top of it with additional features, improvements and optimizations for better usability and network compatibility.

> ⚠️ This project is inspired by v2rayNG and would not exist without the amazing work of its developers. Huge thanks to the original v2rayNG team and the Xray-core community.

# 🚀 Soldier Improvements

Compared to the original project, Soldier Client focuses on adding practical features for daily use.

Current improvements include:

- 🔥 Advanced SNI Spoof Settings
- 🌍 Custom DNS Resolver
- ⚡ Improved TLS Compatibility
- 🛡️ Better Heavy Filtering Support
- 🎨 Refined User Experience
- 🐞 Various bug fixes and optimizations
