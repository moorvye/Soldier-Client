# 🇺🇸 English

## 🛡 About

**Soldier Client** is a fast, lightweight and secure Android VPN client powered by **Xray-core**.

This project is inspired by the excellent **v2rayNG** project and extends it with additional features, better compatibility, improved performance and a cleaner user experience.

> ⚠️ Soldier Client is an independent community project inspired by v2rayNG. Huge thanks to the original developers of **v2rayNG** and **Xray-core** for their incredible open-source work.
